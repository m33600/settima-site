# settima-site

Homepage da **Settima Mecatrônica** — servida em `settima.com.br` pelo GitHub Pages.

A cena de abertura é o desenho do painel anti-colisão do HFORT 4.0
([`hfort-dashboard`](https://github.com/m33600/hfort-dashboard)), portado sem os
controles: teto e margem ficam fixos em 6,0 m e 1,0 m sobre um 8800LI, e a lança
varre continuamente. A cada quadro o cálculo decide quem chega primeiro ao limite
— o cotovelo ou a ponta — e marca esse ponto em laranja. É o mesmo cálculo que
roda no gateway da grua.

Repositório público porque o GitHub Pages exige plano pago para servir a partir de
repositório privado. O conteúdo é institucional; não há segredo aqui.

O acervo técnico continua no Google Sites, linkado no rodapé.
